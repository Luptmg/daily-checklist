Уведомления

Напоминания о порядке приходят в 12:00 и 16:00 по местному времени магазина, пока рабочий день начат.

Рабочий режим

Одна учётная запись с двумя ролями. Переключение доступно только владельцу этой учётной записи.

Нужно настроить подключение

В коде не указаны публичные параметры Supabase. Проверь SUPABASE_URL и SUPABASE_ANON_KEY в начале скрипта. Используй только publishable/anon key, не service_role.

Вход в приложение

Сотрудники входят по логину и паролю. Администратор может использовать свой email.

Регистрация из приложения отключена: учётные записи создаются администратором в Supabase Auth.
